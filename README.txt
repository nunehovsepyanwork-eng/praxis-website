REFERENCE
Built to follow the visual rhythm of the uploaded video:
- generous whitespace
- calm editorial grid
- thin separators
- restrained motion
- no heavy Tailwind dependency
- strong burgundy brand accents
- modular sections

INSTALL
Copy/merge these folders into:
C:\Users\nuneh\praxis-website

- app
- components
- lib
- public

Choose Replace when Windows asks about matching files.

RUN
Use Command Prompt (not PowerShell if script execution is blocked):

cd C:\Users\nuneh\praxis-website
npm run dev

Open:
http://localhost:3000/en
http://localhost:3000/hy
